Help with location

If this app is inside Codex or another app's browser, open it directly in Safari or Chrome and allow location when asked.

  • iPhone: Settings → Privacy & Security → Location Services. Enable location for Safari Websites or your browser.
  • Mac: System Settings → Privacy & Security → Location Services. Enable your browser.
  • Check this website's Location permission in your browser settings, then retry Find me.

You can still pan the map and plan routes without sharing your location.
