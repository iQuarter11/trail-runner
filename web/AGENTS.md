# Trail Runner web app

Standalone static HTML/CSS/JavaScript. Parent Expo instructions apply to the native scaffold only. Run npm run check and npm test before publishing web edits; browser-test meaningful UI changes. Keep OpenStreetMap attribution visible and never prefetch tiles. No secrets belong in browser code.

Hosting is GitHub Pages, from main:/docs. After changing dist/, run npm run prepare-pages, then commit and push both web/dist and docs. Do not publish through Sites.
